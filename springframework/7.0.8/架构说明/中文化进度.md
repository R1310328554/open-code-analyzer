## 如何继续

```bash
# 全量（耗时较长，建议按模块）
./bin/localize-zh.sh springframework 7.0.8

# 按模块
./bin/localize-zh.sh springframework 7.0.8 --modules spring-beans,spring-context
./bin/localize-zh.sh springframework 7.0.8 --modules spring-core,spring-webmvc
```

**注意**：`--force-sync` 会用 `original/` 覆盖整个 `analyzed/`，只在需要「推倒重来」时使用。

## 质量说明

- 批量翻译使用机器翻译 + Spring 领域词表/命名启发式，保证「英文变中文、字段/方法有注释」
- 核心难读类（如 IoC/AOP/事务/MVC 主链路）可再人工精修方法体行内注释
- 对照永远看 `original/`；阅读与学习优先看 `analyzed/`

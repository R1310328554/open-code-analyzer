# spring-webflux

> 响应式 Web 栈

## 模块职责

基于 Reactive Streams 的非阻塞 Web 框架，可运行在 Netty 等服务器。

## 关键包

- `org.springframework.web.reactive`

## 弯弯绕绕（建议精读）

- HandlerMapping/HandlerAdapter 的 reactive 变体
- 与 MVC API 形似神异之处
